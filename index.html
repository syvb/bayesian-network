Publish to GitHub Gist

This creates a new secret gist on your GitHub account containing this network's pyAgrum code, with its layout and evidence, and gives you a short link that opens it in the editor.

Secret gists are unlisted, not private. They don't appear on your profile or in search, but anyone with the link can open this one, and it shows your GitHub username. The link is a snapshot: later edits here won't change it. You can delete the gist on GitHub at any time.

GitHub will ask you to let this editor create gists. GitHub has no narrower permission, so it also allows editing and deleting your other gists; the editor only creates this one. The sign-in is kept in this tab's memory, forgotten when you reload or close it, and stops working on GitHub after 8 hours.
